# 🚀 JokiPro Dashboard - Premium Coding Service

**JokiPro** adalah platform dashboard layanan joki tugas coding dan pemrograman yang dirancang dengan estetika modern, elegan, dan performa tinggi. Dibangun menggunakan **Flutter Web**, dashboard ini memberikan pengalaman pengguna yang mulus tanpa perlu sistem registrasi yang rumit.

## ✨ Fitur Utama

### 📊 Dashboard Overview
Tampilan ringkasan statistik layanan, mulai dari jumlah tugas yang telah diselesaikan hingga rating kepuasan klien. Dilengkapi dengan bagian **FAQ** untuk membantu menjawab pertanyaan umum klien secara instan.

### 💻 Katalog Layanan (Services)
Kategorisasi layanan yang rapi, mencakup:
- **Web Development** (React, Next.js, Laravel, PHP)
- **Mobile App** (Flutter, Android Native)
- **Data Science & AI** (Python, ML)
- **Desktop App** (Java, C++, C#)
- **Bug Fixing & Tugas Akademik**

### 🧮 Kalkulator Harga (Price Calculator)
Fitur interaktif bagi klien untuk menghitung estimasi biaya tugas mereka berdasarkan:
- Jenis layanan
- Tingkat kesulitan (Mudah, Sedang, Sulit)
- Deadline pengerjaan (1 - 14 hari)

### 🔍 Cek Status Progres (Status Checker)
Klien dapat memantau progres pengerjaan tugas mereka secara real-time hanya dengan memasukkan **ID Tugas** mereka (Contoh: `JP-001`).

### ⭐️ Sistem Ulasan (Review System)
Klien dapat memberikan penilaian bintang dan komentar langsung dari dashboard yang akan terintegrasi dengan WhatsApp admin.

### 📲 Integrasi WhatsApp Langsung
Semua aksi pemesanan dan konsultasi akan menghasilkan pesan otomatis yang terformat rapi dan dikirim langsung ke nomor WhatsApp admin (**087865307837**).

## 🚀 Cara Menjalankan Proyek

### Prasyarat
- Flutter SDK terinstal di perangkat Anda.
- Browser (Chrome/Edge) yang sudah dikonfigurasi.

### Langkah-langkah
1. **Clone/Download Proyek**
   Masuk ke folder proyek:
   ```powershell
   cd joki
   ```

2. **Install Dependensi**
   Jalankan perintah berikut untuk mengunduh semua package yang diperlukan:
   ```powershell
   flutter pub get
   ```

3. **Jalankan Aplikasi**
   Pilih target browser Anda:
   ```powershell
   # Jalankan di Chrome
   flutter run -d chrome

   # Jalankan di Microsoft Edge
   flutter run -d edge
   ```
