================================================================================
PROJECT BLUEPRINT: JOKIPRO DASHBOARD
================================================================================
Version: 1.0.0
Author: JokiPro Dev Team
Concept: Premium Coding & Assignment Service Dashboard
Technology: Flutter Web (Dart)
================================================================================

1. PROJECT VISION
--------------------------------------------------------------------------------
Membangun platform satu pintu (one-stop solution) untuk layanan joki coding yang
mengutamakan kecepatan, estetika premium, dan kemudahan akses tanpa sistem
registrasi/login untuk meningkatkan conversion rate pemesanan.

2. USER FLOW (WORKFLOW)
--------------------------------------------------------------------------------
[Client] -> [Landing Dashboard] -> [Pilih Layanan / Cek Estimasi Harga]
    |
    |-----> [Konsultasi via WhatsApp] -> [Pengerjaan Admin]
    |
    |-----> [Cek Progres via ID Tugas] -> [Selesai]
    |
    |-----> [Berikan Ulasan / Bintang]

3. APP ARCHITECTURE (SITEMAP)
--------------------------------------------------------------------------------
- ROOT (MaterialApp)
  - LayoutWrapper (Responsive: Sidebar/Drawer)
    - [Page 0] Dashboard Home: Stats Cards, Welcome Banner, FAQ Section.
    - [Page 1] Services: Grid of service categories (Web, Mobile, AI, etc).
    - [Page 2] Price Calculator: Input-based dynamic pricing logic.
    - [Page 3] Status Checker: Search-based project progress tracking.
    - [Page 4] Portfolio: Showcase of previous works.
    - [Page 5] Review System: Star rating and feedback form.
    - [Page 6] Contact: Multi-channel contact information.

4. TECHNICAL STACK
--------------------------------------------------------------------------------
- Frontend Framework: Flutter Web
- State Management: Provider (for reactive updates in Calculator & Status)
- Styling:
  - Color Palette: #0F172A (BG), #6366F1 (Primary), #EC4899 (Secondary)
  - Typography: Outfit (Heading), Inter (Body)
  - Effects: Glassmorphism, Animated Switcher Transitions.
- Icons: FontAwesome Icons
- API/Integration: WhatsApp Click-to-Chat (wa.me)

5. DATA MODELS & LOGIC
--------------------------------------------------------------------------------
- ServiceModel: title, description, icon, basePrice.
- DashboardProvider:
  - Tab state management.
  - Pricing algorithm: (BasePrice * DifficultyMultiplier * DeadlineMultiplier).
  - Status Checking: Mock async logic for project tracking.
- WhatsApp Message Templates:
  - Order: "Halo Admin, saya ingin order [Service]..."
  - Estimate: "Estimasi harga saya: [Price] untuk [Type]..."
  - Review: "Review JokiPro: [Star]/5 - [Comment]..."

6. SECURITY & ACCESS
--------------------------------------------------------------------------------
- No Authentication: Full access for public users.
- Input Validation: Validating Job ID format (JP-XXX).
- Sanitization: URI encoding for all WhatsApp messages.

7. FUTURE ROADMAP (PROPOSED)
--------------------------------------------------------------------------------
- Admin Dashboard: Untuk mengelola antrean tugas secara real-time.
- Payment Gateway Integration: Midtrans/Xendit untuk pembayaran otomatis.
- Cloud Database: Integrasi Firebase untuk penyimpanan ulasan & status permanen.
- Real-time Chat: Chat widget internal menggantikan/mendampingi WhatsApp.
